Exercício Prático - WEBSTORAGE

Desenvolvimento de Interfaces WEB - Sistemas de Informação

Prof. Paulo Henrique Rodrigues

Instruções

Armazene as preferências do usuário relativas a tamanho da fonte, cores da fonte e do fundo, para o elemento que contém o nome do cientista da computação holandês Edsger Dijkstra.

Resolva essa atividade utilizando ambos os métodos LocalStorage e SessionStorage.

localStorage: Armazena os dados sem prazo de expiração. As informações persistem mesmo após o navegador ser fechado.

sessionStorage: Armazena os dados apenas durante a sessão atual do navegador. Os dados são perdidos quando a aba ou janela do navegador é fechada.

Ambas as funcionalidades utilizam os métodos:

  • setItem(chave, valor) — armazena uma chave, com o respectivo valor;
  • getItem(chave) — recupera o valor de uma chave;
  • removeItem(chave) — apaga uma chave do armazenamento (e seu valor);
  • length — informa a quantidade de chaves armazenadas para este site;
  • key(n) — retorna o nome da n-ésima chave;
  • clear() — apaga todas as chaves e valores deste site.
  • JSON.stringify() — converter um objeto JSON em String.
  • JSON.parse() — converter uma string em um objeto JSON.
